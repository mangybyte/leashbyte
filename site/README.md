# LeashByte website

The static site for leashbyte.com, built with Vite, React and Tailwind CSS. The design and code are original to this project.

## Local development

You'll need Node 22.12 or later.

```bash
npm ci
npm run dev
```

## Static build

```bash
npm ci
npm run build
```

The build writes the whole site to `dist`. It doesn't need an application server, and it loads no external fonts, CDN assets, analytics or tracking scripts.
